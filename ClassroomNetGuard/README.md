# 上网管控系统（教师端 + 学生端）

单间教室局域网的白名单上网管控系统：教师端远程控制学生端能访问哪些网站、能否下载，支持课堂管控/自由模式切换与网页临时解锁。

## 功能

- **纯白名单管控**：默认全拦，只放行白名单内规则；支持域名（`baidu.com` 含子域名）、通配域（`*.edu.cn`）、IP 单机（`192.168.1.50`）、IP 段通配（`192.168.1.*`）、IP 网段（`192.168.1.0/24`）；被拦显示"访问已被拦截"提示页并上报教师端
- **下载管控**：教师端可开启「禁止下载」，或按文件类型（pdf/docx/pptx/zip/xlsx）与大小上限放行（代理层判定，HTTP 生效）
- **课堂/自由模式**：全局一键切换；也可对每台学生机单独设置模式，未单独设置的设备跟随全局
- **网页临时解锁**：学生机在拦截页输入解锁密码可临时放行 30 分钟；密码按设备独立，教师端可设自定义密码或一键生成"默认密码"（计算机名×当天日期取后 6 位，每机独立、每天变化）；学生机上线未设置密码时教师端自动生成默认密码；支持导出全部密码 CSV
- **解锁撤销**：教师端下发任何新策略（改白名单/切模式/手动重新拦截）即撤销该设备解锁，并主动断开已建立的网页连接，刷新后立即恢复拦截
- **实时监控**：教师端以设备图标墙展示每台学生机（计算机名 + IP + 状态色），查看在线状态、拦截次数、实时日志
- **离线兜底**：学生端断线沿用最后策略，默认保持拦截
- **即插即用**：学生端开机自动通过 UDP 广播发现教师机，无需配置 IP；也可在安装时指定教师机 IP

## 架构

```
┌─────────────────────┐   TCP 9999（JSON 帧：策略/心跳/日志/指令）   ┌────────────────────────────┐
│  教师端 (WPF)        │◄───────────────────────────────────►│  学生端                     │
│  · TCP 服务器         │       UDP 9998 发现教师机            │  · 管控服务 (Windows 服务)   │
│  · 白名单/下载策略      │                                     │    - 本地代理 127.0.0.1:8888 │
│  · 设备图标墙/实时日志   │                                     │    - 策略API 127.0.0.1:8890  │
│  · 按设备模式/解锁密码   │                                     │    - 命名管道(托盘查询)      │
└─────────────────────┘                                     │  · 托盘程序(系统代理/状态)    │
                                                             └────────────────────────────┘
```

管控原理：托盘程序把学生机系统代理指向 `127.0.0.1:8888`；管控服务内的本地代理按白名单判定每个请求——HTTP 按 Host 头判定，HTTPS 在 CONNECT 隧道内完成 TLS 解密（本机信任自签 CA）后按域名判定，命中白名单才转发，否则返回拦截页。

## 编译

要求：.NET SDK 8.0+（Windows）。

```powershell
# 方式一：命令行
dotnet build "上网管控系统.sln" -c Release

# 方式二：一键发布（自包含 exe，目标机无需装 .NET）
.\scripts\publish.ps1
```

发布产物：
- 教师端：`publish\teacher\TeacherConsole.exe`
- 学生端：`publish\student\StudentService.exe` + `StudentTray.exe`

## 部署

### 教师机
1. 运行 `TeacherConsole.exe`（`publish\teacher\`）
2. 策略自动保存到 `%ProgramData%\NetGuard\teacher-policy.json`，重启恢复
3. 放行教师机防火墙入站 TCP 9999 / UDP 9998：
   ```powershell
   netsh advfirewall firewall add rule name="NetGuard" dir=in action=allow protocol=TCP localport=9999
   netsh advfirewall firewall add rule name="NetGuard-UDP" dir=in action=allow protocol=UDP localport=9998
   ```

### 学生机（每台）
1. 拷贝 `学生端安装包\` 整个目录到学生机
2. 以管理员运行 `setup.bat`（自动卸载旧版 → 安装服务 → 导入 CA → 启动托盘；安装时可输入教师机 IP）
3. 无需手动配置：默认通过 UDP 广播自动发现教师机；如需固定，`%ProgramData%\NetGuard\config.json` 写入 `{ "teacherHost": "192.168.1.10" }`

### 解锁密码
- 教师端设备详情可设置自定义密码，或点"默认密码"按"计算机名×当天日期取后 6 位"生成（每机独立、每天变化）
- 学生机上线且未设置过密码时，教师端自动生成当天默认密码
- 教师端顶部"导出密码"可导出全部设备的解锁密码 CSV

## 调试

学生端服务支持前台调试（无需安装为服务）：
```powershell
.\StudentService.exe --console
```
日志位置：`%ProgramData%\NetGuard\logs\`。

## 已知边界

- 下载管控在代理层判定，HTTPS 隧道内的下载暂不拦截（浏览器扩展方案已被弃用）
- 代理处理 HTTP/HTTPS（CONNECT 隧道）流量；QUIC/HTTP3 场景建议在学生端浏览器关闭或由防火墙兜底
- 通信为明文 TCP + JSON；生产环境建议叠加 TLS 与设备密钥认证
- 学生端离线时保持「最后策略 + 默认拦截」，教师端设备列表可见离线状态

## 合规提示

本系统用于自有教学环境的网络行为管理，请在部署前向学生公示网络使用规范，并遵守所在地个人信息保护相关法规。
