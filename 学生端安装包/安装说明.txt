上网管控学生端 - 安装包
============================

【包含内容】
  - student.zip   ：管控服务 + 托盘程序 + 浏览器扩展（已打包）
  - setup.bat     ：一键安装程序（双击运行）
  - install.ps1   ：安装脚本（由 setup.bat 自动调用，无需手动运行）
  - 本说明文件

【安装步骤】（每台学生机操作一次）
1. 把整个"学生端安装包"文件夹拷贝到学生机（U 盘 / 共享文件夹均可）。
2. 双击 setup.bat。
3. 弹出"用户账户控制"时点击【是】（需要管理员权限）。
4. 安装程序会先询问【教师端 IP】：
   - 输入教师机的 IP 地址（如 192.168.1.10）→ 学生端直接连接该教师机；
   - 直接回车 → 学生端启动时在局域网内自动搜索教师机。
5. 等待自动完成：
   ① 卸载旧版本：停止并删除旧服务 → 结束旧托盘 → 移除旧自启 → 删除旧程序文件
   ② 解压新程序到 C:\Program Files\NetGuard
   ③ 写入教师端 IP 配置
   ④ 安装并启动管控服务 NetGuardStudentService（开机自动运行）
   ⑤ 导入 HTTPS 管控证书到系统信任根
   ⑥ 立即启动托盘程序，把系统代理指向本地白名单代理
   ⑦ 托盘设为所有用户开机自启（每次登录自动生效）
6. 完成。**无需安装任何浏览器扩展**，也没有"开发人员模式"提示。

【修改教师端 IP（安装后）】
  配置文件：C:\ProgramData\NetGuard\config.json
  修改其中 TeacherHost 为新的教师机 IP（注意大小写），保存后重启服务：
    以管理员身份运行命令提示符：
      sc stop NetGuardStudentService
      sc start NetGuardStudentService
  或在教师机 IP 变化时直接重新运行 setup.bat 重装。

【重要 - 上网拦截生效条件】
- 拦截依赖"托盘程序"把系统代理指向 127.0.0.1:8888：
  · 任务栏右下角应出现盾牌托盘图标（没有 → 手动双击
    C:\Program Files\NetGuard\StudentTray.exe）
  · 双击托盘图标可查看状态：应显示"已连接教师端 · 课堂管控"
- 浏览器必须在代理生效后重新打开：已开着的浏览器/网页
  不会自动切换代理，请完全退出 Edge 再重新打开。
- 拦截提示页：
  · http 网站 → 直接显示红色"访问已被拦截"页面
  · https 网站 → 安装程序已装入管控证书（HTTPS 解密），
    同样显示"访问已被拦截"页面
  · 若 https 仍显示"无法访问此页面"，说明证书未信任：
    以管理员运行命令提示符执行
      certutil -addstore -f Root "C:\ProgramData\NetGuard\cert\ca.pfx"
    后重启浏览器。（新安装包会自动装入，一般无需手动）
- 验证：白名单外的网站应显示拦截页；白名单内网站正常。

【教师端 - 主界面】
- 主界面以「班级设备」图标墙为主：每台学生机显示为一张卡片
  （电脑图标 + 计算机名 + IP + 状态），不显示"学生机"字样。
- 卡片颜色：在线绿色 / 离线灰色 / 放行中橙色。
- 卡片操作：
  · 卡片下方按钮：单独切换该设备的「管控 / 自由」模式
  · 学生机放行中时卡片出现红色「重新拦截」按钮（立即恢复管控）
  · 点击卡片打开详情：设置/清除该机的解锁密码、重新拦截
- 右上角「设置」按钮打开设置窗口：网站白名单与下载策略。
- 右侧为实时日志（拦截/放行/策略）。

【教师端 - 网站白名单（设置窗口）】
- 支持格式：
  · 域名：baidu.com（含全部子域名）
  · 通配域：*.edu.cn
  · IP 地址：192.168.1.50
  · IP 段通配：192.168.1.*（允许 192.168.1.x 全部）
  · IP 网段：192.168.1.0/24（CIDR 写法）
- 修改即时下发到全部学生机。

【教师端 - 设备解锁密码（按学生机独立）】
- 教师端主界面设备卡片上有"解锁密码"输入框 + "设置"按钮：
  · 给某台学生机输入密码 → 点"设置" → 立即下发到该学生机并持久化
  · 每台学生机密码独立，互不影响
  · 密码留空点"设置" = 清除该学生机的解锁密码
- 点击设备卡片打开详情，有「默认密码」按钮：按
  计算机名转数字 × 当天日期转数字，乘积取后 6 位，一键生成并填入；
  每天密码自动变化，需当天重新生成。
- 主界面右上角「导出密码」：导出全部学生机解锁密码清单（CSV 文件）。
  已设置密码导出实际值；未设置的导出当天默认密码（标注"未应用"）。
- 效果：学生访问被拦截网站时，拦截页出现"解锁上网"按钮 +
  密码输入框；输入正确密码后该学生机临时放行 30 分钟，
  到期自动恢复课堂管控（解锁期间不受白名单限制）。
- 设备卡片会显示"解锁状态：放行中/管控中"：
  · 学生解锁后教师端实时变为"放行中"
  · 学生机解锁期间，设备卡片出现红色"重新拦截"按钮：
    点击后立即恢复该学生机的课堂管控（无需等 30 分钟到期）
- 未设置密码的学生机，拦截页只显示"请联系教师"，无法自行解锁。

【学生端 - 拦截页解锁】
- 白名单外网站被拦截时，拦截页底部有解锁输入框：
  1. 输入教师下发的解锁密码 → 点"解锁上网"
  2. 提示"解锁成功"后，关闭该页面，重新打开原网页即可访问
  3. 30 分钟后自动恢复管控；错误密码会提示重新输入

【说明】
  - 管控服务：NetGuardStudentService（开机自动运行，连接教师端获取白名单策略）
  - 程序目录：C:\Program Files\NetGuard
  - 日志目录：C:\ProgramData\NetGuard\logs
  - 白名单：默认【纯空白名单】——未收到教师端策略时全部网站拦截；
    放行哪些网站由教师端白名单列表决定（教师端保存后自动下发，版本号 +1）
  - 下载管控：由本地代理完成（无需浏览器扩展）。
    · http 下载（普通网页下载）：按教师端下载策略拦截（类型/大小）
    · https 下载：https 加密隧道内无法识别下载内容，暂不拦截
  - 托盘程序（右下角盾牌图标）右键菜单**不提供"退出"**，
    防止学生自行退出导致管控失效；学生机重启后全部自动生效

【卸载】
  以管理员身份运行命令提示符：
    sc stop NetGuardStudentService
    sc delete NetGuardStudentService
  然后删除 C:\Program Files\NetGuard 目录，
  并删除公共启动文件夹中的 NetGuardStudentTray.vbs：
    C:\ProgramData\Microsoft\Windows\Start Menu\Programs\StartUp\
